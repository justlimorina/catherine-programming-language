# Catherine Programming Language
> Catherine is an experimental programming language designed for simplicity, human readability, and intuitive syntax. This language is built on top of C++.

**English** | [Tiếng Việt](README_vi.md)

## Current Features Overview
* **Philosophy**: Simple, concise, and easy to understand for beginners.
* **Supported Data Types**:
  * `number`: Numeric values (includes `int`, `float`, `double`).
  * `string`: Text strings.
  * `boolean`: Truth values (`true`/`false`).
  * `struct`: Custom user-defined data structures.
  * `Type[]`: Dynamic array lists containing elements of the same type.
* **File Extension**: Uses the `.rine` file extension.
